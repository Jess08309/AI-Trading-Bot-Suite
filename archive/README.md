# Archive

This directory documents the retired-bot artifacts removed during the
2026-09-27 portfolio consolidation. On 2026-10-02, the retired Oracle Cloud
systemd units and deployment scripts were removed because Oracle Cloud is no
longer used. Production runs as a single `cryptobot` systemd service on a
DigitalOcean droplet, with code deployed by running `git pull` on the droplet.

The removed artifacts remain available in the
`archive/four-bot-portfolio-2026-09-27` branch and in git history.
